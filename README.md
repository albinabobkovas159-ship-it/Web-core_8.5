# Ремонт техники различных брендов

Учебный проект в рамках курса Web Core.
Адаптивная вёрстка блока с брендами по макету Figma.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Swiper.js
- Методология БЭМ

## Реализованный функционал

- Адаптивная вёрстка.
- Слайдер с пагинацией на мобильных устройствах.
- Отключение Swiper с помощью метода `destroy()`.
- Расположение карточек с помощью CSS Grid.
- Раскрытие и скрытие списка брендов.
- Динамическое изменение текста кнопки.
- Плавный поворот стрелки на 180 градусов.
